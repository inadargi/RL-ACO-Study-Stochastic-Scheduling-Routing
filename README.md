
# 🚚 RL-ACO Study: Stochastic Scheduling & Routing

An implementation of a hybrid **Q-learning + Ant Colony Optimization (ACO)** approach for the **Stochastic Home Health Care Scheduling and Routing Problem (SHHCSRP)**, a challenging combinatorial optimization problem derived from the Vehicle Routing Problem.

## 📋 Overview

This project explores how **Reinforcement Learning and Ant Colony Optimization** can be combined to solve large-scale stochastic scheduling and routing problems.

The objective is to assign customer demands to available vehicles while minimizing routing and waiting costs and maximizing fulfilled demands.

I designed and implemented the hybrid optimization workflow using **tabular Q-learning** as the high-level decision-making agent and **Ant Colony Optimization** as the low-level routing optimizer.

The Q-learning agent operates on a hierarchical **Markov Decision Process (MDP)**. At each state, the agent evaluates the current environment, selects an available vehicle, and receives a reward based on the routing solution generated by the ACO component.

## 🔬 Problem Formulation

The **Stochastic Home Health Care Scheduling and Routing Problem** involves assigning a set of customer demands to available vehicles while considering routing constraints, resource availability, demand fulfillment, and waiting costs.

The primary objective is to:

* Maximize fulfilled customer demands
* Minimize waiting costs
* Generate feasible vehicle routes
* Learn better vehicle-selection decisions through repeated interaction with the environment

## 🤖 Q-Learning Component

The Q-learning agent learns a policy for selecting vehicles based on the current state of the scheduling environment.

For each state, the agent:

1. Observes the current scheduling state.
2. Selects an available vehicle as an action.
3. Passes the decision to the routing optimization layer.
4. Receives a reward based on the resulting routing solution.
5. Updates the Q-table using the observed reward and next state.

The Q-table gradually captures which vehicle-selection decisions are more beneficial for different scheduling states.

## 🐜 Ant Colony Optimization Component

The ACO component handles the routing problem for the selected vehicle.

The algorithm:

1. Initializes a population of ants.
2. Constructs candidate routes.
3. Evaluates route quality.
4. Updates pheromone information.
5. Uses pheromone and heuristic information to guide subsequent solutions.
6. Returns the best routing solution found.

The resulting routing performance is then used by the Q-learning layer as feedback.

## 🔗 Hybrid RL + ACO Architecture

The key idea of the project is to divide the optimization problem into two levels:

**Q-learning → strategic decision-making**

The RL agent determines which vehicle should be selected based on the current state.

**ACO → route-level optimization**

ACO determines an effective route for the selected vehicle.

This creates a hierarchical optimization framework where reinforcement learning handles the higher-level scheduling decision while ACO handles the lower-level combinatorial routing problem.

## 💡 Key Findings

The project provided several important observations about applying tabular reinforcement learning to combinatorial optimization:

### 1. State Representation Matters

A state that does not capture enough information about remaining demands, available resources, and routing conditions makes it difficult for Q-learning to learn meaningful policies.

### 2. Reward Design Is Critical

The reward must accurately represent the optimization objective. Poorly shaped rewards can cause the agent to learn behaviour that does not correspond to the desired routing strategy.

### 3. RL + Stochastic Optimization Is Challenging

Because the ACO component can produce different solutions during different runs, the same high-level action may result in different rewards. This introduces additional uncertainty into the Q-learning process.

### 4. Scalability

Tabular Q-learning becomes increasingly difficult to apply as the state space grows. Large-scale combinatorial problems can produce an enormous number of possible states and actions.
